# 📐 Тренажёр для поступления в 8 класс Аничкова лицея · Алгебра + Геометрия

Интерактивный сайт-тренажёр для подготовки к вступительному экзамену «Математика и логика» в 8 класс Аничкова лицея (Санкт-Петербург). Задачи взяты из вступительных экзаменов за 2006–2026 годы (архив [spbal.ru](https://spbal.ru/node/11)) и из пособия Л. С. Михлина «Пособие для поступающих в 8–10 классы физико-математических школ».

Всего **12 модулей**, **30 уроков** (60 вариантов: классные работы и домашние задания), **322 задания** и **337 интерактивных полей ответа**. Ответ вводится в поле, выбирается из вариантов или отмечается перетаскиванием точки на клетчатом чертеже. К каждому уроку есть памятка с теорией.

🌐 **Сайт:** <https://baikovaalina.github.io/anichkov8-trenazhor/>
🤖 **Telegram-бот для приёма результатов:** [@ZVEROKZVEROKBOT](https://t.me/ZVEROKZVEROKBOT)

Дизайн, структура, логика проверки, формат сообщения в Telegram и схема работы с секретами скопированы из тренажёра [math6-trenazhor](https://github.com/BaikovaAlina/math6-trenazhor).

## 🚀 Особенности

- **Содержание под формат экзамена Аничкова лицея.** В экзамене 7 задач: №1 «математическая база», №2 вычисления, №3 выражение, №4 уравнения и линейная функция, №5 текстовая задача, №6 геометрия 7 класса, №7 логика. Больше всего заданий именно этих типов. Темы из Михлина и опережающие темы (корни, прогрессии, окружность, подобие, векторы) отмечены уровнем «Углублённый» или «Олимпиадный».
- **Урок = классная работа + домашнее задание.** Страница `lesson.html#/lesson/N` показывает теорию, обе работы и статистику. Через неё же отправляется сводный результат в Telegram.
- **Три формата заданий:** ввод ответа, выбор варианта (кнопки) и перетаскивание точки на клетчатом чертеже (мышь, палец, стрелки клавиатуры).
- **Проверка ответов** (`js/checker.js`):
  - числа сравниваются с допуском ±0,01: `3/4` = `0,75` = `0.75` = `6/8`;
  - понимает смешанные числа (`-1 6/7`), записи вида `x = 5`, градусы и единицы измерения (`45°`, `7 см`);
  - списки сравниваются без учёта порядка (`1; 5` = `5, 1`), координаты записываются как `(2; 3)`;
  - строки нормализуются: trim, нижний регистр, `ё`→`е`, запятая→точка.
- **Мгновенная обратная связь.** Верный ответ подсвечивается зелёным, неверный — красным, и появляется объяснение решения.
- **Статистика в localStorage** (`stats.html`): по текущей сессии и по каждому уроку (попытки, лучший результат, последний результат). Есть кнопка сброса.
- **Telegram.** Кнопка «Отправить результат в Telegram» есть и на странице урока, и в тренажёре. В сообщении указаны: Ученик, Урок, Результат X/Y, Время mm:ss, процент, оценка и список ошибок. Запасной вариант — скачать отчёт в `.txt`.
- **Бесплатно и без сервера.** Чистый HTML/CSS/JS на GitHub Pages. Токен бота хранится только в GitHub Secrets.

## 🤖 Настройка Telegram-бота

### 1. Создать бота (@BotFather)
1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Укажите имя (например, «Аничков 8») и username, который заканчивается на `bot`.
3. BotFather пришлёт токен вида `1234567890:AA...`. **Никому его не показывайте и не кладите в код.**
4. Откройте своего бота и нажмите **Start**. Пока вы этого не сделали, бот не может вам писать.

### 2. Узнать Chat ID (@userinfobot)
1. Откройте [@userinfobot](https://t.me/userinfobot) и нажмите **Start**. В ответе будет ваш `Id`: это и есть Chat ID.
2. Если результаты должны приходить в группу: добавьте бота в группу и напишите в ней любое сообщение. Затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":-100...}`. ID группы начинается с минуса.

### 3. Добавить секреты в GitHub
**Settings → Secrets and variables → Actions → New repository secret**:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | ваш Chat ID |

После этого запустите **Actions → Deploy to GitHub Pages → Run workflow** или сделайте любой коммит в `main`. Во время деплоя команда `sed` заменит в `js/config.js` плейсхолдеры `__TELEGRAM_BOT_TOKEN__` и `__TELEGRAM_CHAT_ID__` на значения секретов. В самом репозитории остаются только плейсхолдеры.

### 4. Включить GitHub Pages
**Settings → Pages → Build and deployment → Source: GitHub Actions**. Через 1–2 минуты после деплоя сайт откроется по адресу `https://<логин>.github.io/anichkov8-trenazhor/`.

> ⚠️ **Важно про безопасность.** На статическом сайте токен попадает в итоговый JS-файл, и любой может увидеть его в DevTools. Такая же схема у эталонного проекта. Через бота можно только отправлять сообщения, поэтому риск ограничен спамом, но заводите для тренажёра **отдельного бота**. Если нужна полная защита, вынесите отправку в бесплатный Cloudflare Worker: токен хранится в его переменных окружения, а сайт вызывает `fetch('https://<worker>.workers.dev', {method:'POST', body})`. Это потребует изменить одну функцию `sendToTelegram()` в `js/telegram.js`.

### 5. Перевыпустить токены
- **Токен бота:** в @BotFather отправьте `/mybots` → выберите бота → **API Token → Revoke current token**. Новый токен вставьте в секрет `TELEGRAM_BOT_TOKEN` (Settings → Secrets → карандаш → Update) и перезапустите деплой. Старый токен перестаёт работать сразу.
- **GitHub-токен (PAT):** GitHub → **Settings → Developer settings → Personal access tokens** → найдите токен → **Delete**. Если нужен новый, выпустите его с минимальными правами и коротким сроком действия.
- **Chat ID** не секретен и не перевыпускается. Чтобы отчёты приходили в другой чат, просто поменяйте секрет `TELEGRAM_CHAT_ID`.

## ✏️ Как обновить банк задач

**Способ 1 — правка JSON (просто).**
1. Откройте `data/tasks.json` и найдите вариант, например `"K-22"`.
2. Задание устроено так: `parts` — текст с полями `{"_input": i}`, `inputs[i]` — ответ.
   ```json
   {"label": "а) Найдите угол", "parts": ["Ответ:", {"_input": 0}],
    "inputs": [{"a": "3/4|0,75", "type": "", "g": "q1r0", "w": 1}], "e": "Объяснение при ошибке"}
   ```
   - `a` — допустимые ответы через `|`;
   - `type`:
     - `""` — число;
     - `list` — набор без учёта порядка;
     - `coords` — координаты `(x;y)`;
     - `choice` — выбор, варианты задаются в `options`;
     - `point` — точка на чертеже, сетка задаётся в `grid`;
     - `text` — строка.
3. Темы и теория уроков лежат в `data/lessons.json`.
4. Закоммитьте изменения. Actions сам пересоберёт `js/tasks.js` (`tools/build_tasks.py`), прогонит тесты (`tools/test.js`) и опубликует сайт. Чтобы проверить локально: `python3 tools/build_tasks.py && node tools/test.js`.

**Способ 2 — генератор (для больших правок).** Задания описаны на Python в `tools/generator/content_*.py` с помощью функций `R` (поле ввода), `M` (несколько полей), `C` (выбор), `P` (точка на чертеже), `Q` (задача) и `lesson(...)`. Укажите для задания `chk=` — точное значение, вычисленное через `Fraction`, — и генератор сам сверит его с ответом. Запуск: `python3 tools/generator/build.py`. Скрипт перезапишет `data/*.json` и `js/tasks.js`.

```bash
python3 -m http.server 8000   # затем откройте http://localhost:8000
node tools/test.js            # 780+ проверок: чекер и самопроверка всех ответов
```
Для локальной отправки в Telegram откройте на сайте «⚙️ Настройки Telegram» и введите токен и Chat ID. Они сохранятся только в localStorage вашего браузера.
